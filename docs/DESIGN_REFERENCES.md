# Design references

The territory loop is inspired by the broad arcade conventions popularized by Paper.io 2: continuous movement, vulnerable trails and loop-based capture. Jinshi Territory uses original TypeScript code, protocol types, UI, bot behavior and procedural visuals.

No Paper.io 2 source code, artwork, audio, branding or proprietary data is included. The implementation uses a server-authoritative ownership grid and flood-fill capture system designed specifically for this project.
